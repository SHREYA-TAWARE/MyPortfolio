# Divine Blessings - Spiritual E-Commerce Website

A comprehensive spiritual e-commerce platform similar to ekisandarshan.in, offering religious and devotional items, online darshan, puja bookings, and spiritual consultations.

## 🕉️ Features

### E-Commerce Functionality
- **Product Catalog**: Browse spiritual items with categories (Idols, Jewelry, Books, Incense, Gemstones)
- **Product Details**: Detailed product pages with specifications, benefits, and reviews
- **Shopping Cart**: Add/remove items, quantity management, persistent cart storage
- **Secure Checkout**: Complete checkout process with multiple payment options
- **Order Management**: Order confirmation, tracking, and history

### Spiritual Services
- **Online Darshan**: Live temple darshan streaming with schedule management
- **Puja Booking**: Schedule personalized rituals and ceremonies
- **Spiritual Consultation**: Book sessions with astrologers and spiritual guides
- **Wishlist**: Save favorite products for later

### User Experience
- **Authentication**: Complete login/signup system with user profiles
- **Responsive Design**: Mobile-friendly across all devices
- **Search Functionality**: Real-time product search with suggestions
- **Notifications**: Toast notifications for user actions
- **Clean UI**: Devotional design with serene colors and spiritual aesthetics

## 🎨 Design Philosophy

The website follows a spiritual and devotional design approach:
- **Colors**: Earth tones (Saddle Brown), Divine gold (Goldenrod), Saffron orange
- **Typography**: Elegant serif fonts for headings, clean sans-serif for content
- **Imagery**: Spiritual symbols, temple motifs, and sacred geometry
- **User Experience**: Peaceful, intuitive navigation with spiritual context

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - runs entirely in the browser

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. The website will load with all functionality available

### File Structure
```
Divine-Blessings/
├── index.html              # Main homepage
├── styles/
│   ├── main.css            # Main stylesheet
│   └── responsive.css      # Mobile responsive styles
├── js/
│   ├── main.js             # Core functionality
│   ├── cart.js             # Shopping cart features
│   ├── auth.js             # Authentication system

├── images/
```

## 🛍️ Using the Website

### Shopping Experience
1. **Browse Products**: Navigate through different categories
2. **View Details**: Click on product images or titles for detailed information
3. **Add to Cart**: Select quantity and add items to your shopping cart
4. **Checkout**: Complete purchase with shipping and payment information
