# 🌱 कृषिसागर (Krushisagar) - Spiritual Agricultural E-commerce Website

A beautiful, spiritual e-commerce website for agricultural products including seeds, fertilizers, pesticides, and anticides. Built with pure HTML, CSS, and JavaScript following devotional design principles.

## 🌟 Features

### 🛒 E-commerce Functionality
- **Product Catalog**: Seeds, fertilizers, pesticides, and anticides with detailed descriptions
- **Shopping Cart**: Add/remove items, quantity management, persistent storage
- **Secure Checkout**: Multi-step checkout process with order summary
- **Order Management**: Order confirmation, tracking, and success pages
- **Search & Filter**: Product search and category-based filtering

### 🧘 Spiritual Design
- **Devotional UI**: Serene colors (sage green, saffron, terracotta, sacred gold)
- **Sanskrit Quotes**: Spiritual verses with translations throughout the site
- **Sacred Typography**: Special fonts for Sanskrit text and spiritual elements
- **Peaceful Animations**: Gentle floating elements and smooth transitions

### 👤 User Experience
- **Authentication**: Login/register system with user management
- **Consultation Booking**: Expert agricultural consultation scheduling
- **Mobile Responsive**: Fully responsive design for all devices
- **Accessibility**: WCAG compliant with keyboard navigation and screen reader support

### 🔧 Technical Features
- **Pure Vanilla Stack**: No frameworks - just HTML, CSS, and JavaScript
- **Local Storage**: Client-side data persistence
- **Progressive Enhancement**: Works without JavaScript for basic functionality
- **Performance Optimized**: Fast loading with efficient code
- **SEO Friendly**: Semantic HTML and proper meta tags

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Web server (for local development)

### Installation
1. Clone or download the repository
2. Open `index.html` in a web browser
3. For local development, use a simple HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

### Usage
1. **Browse Products**: Navigate through different categories
2. **Add to Cart**: Select quantity and add items to cart
3. **User Account**: Register/login for personalized experience
4. **Checkout**: Complete purchase with delivery details
5. **Consultation**: Book expert agricultural advice
